# Алгоритмы и их реализация
Приветики! Это репозиторий посвящённый выполнению домашних заданий, связанных с алгоритмами. Буду стараться писать красиво и адекватно, но не обещаю ^-^. Реализация будет на нескольких языках программирования. В первую пору, репозиторий будет реализовываться по проще, так как сложновато успевать выполнять домашки по другим предметам. К слову, по другим предметам тоже будут репозитории. 
---
# Языки программирования
Репозиторий реализует алгоритмы на двух языках программирования C# и Java. Со времен, выполненные задачи на этих языках будут развиваться в более углублённую реализацию(например, написание pom.xml или полноценную сборку проектов с нуля).
